# 视频拆解与复刻清单

整理了一批用于「拆解参考视频、再复刻」的开源项目，以及 X 上相关的帖子。

## GitHub 开源项目

- [edenfunf/reelmimic](https://github.com/edenfunf/reelmimic)：最完整。拆解参考视频的剪辑节奏、镜头、转场、色彩和运镜，生成分镜方案后由多个 AI 代理分工制作，本地运行。
- [lewisluc87-hub/video-to-prompt](https://github.com/lewisluc87-hub/video-to-prompt)：本地镜头检测、OCR、运镜分析，生成 Sora、Runway、Veo 提示词，支持纯离线模式。
- [getvrex/video-analyst](https://github.com/getvrex/video-analyst)：用 Gemini 分析 YouTube 或 TikTok 视频，输出 Veo 3 复刻方案。
- [keng1304/video-breakdown](https://github.com/keng1304/video-breakdown)：拆解镜头、运镜、色彩、音乐结构，并为每个镜头生成 Seedance 和 Kling 提示词。
- [dingtom336-gif/viral-video-replicator](https://github.com/dingtom336-gif/viral-video-replicator)：面向爆款带货视频，逆向分析并生成 Seedance 2.0 复刻提示词。
